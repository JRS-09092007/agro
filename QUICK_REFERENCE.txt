🚀 QUICK START (3 STEPS)
═════════════════════════════════════════════════════════════════════════════

STEP 1: Google Cloud Setup (5 minutes)
  1. Go to console.cloud.google.com
  2. Create project: "KrishiMitra"
  3. Enable APIs: Gemini, Speech-to-Text, Text-to-Speech
  4. Create API key
  5. Copy the key

STEP 2: Add API Key to App (2 minutes)
  1. Open lib/screens/ai_chat_screen.dart
  2. Find: const geminiApiKey = 'YOUR_GEMINI_API_KEY_HERE';
  3. Replace with your actual API key

STEP 3: Test (3 minutes)
  1. Run: flutter pub get
  2. Open app → Select language
  3. Go to Dashboard → AI Assistant
  4. Test: Type a question or tap microphone to speak

👥 USER EXPERIENCE EXAMPLE
═════════════════════════════════════════════════════════════════════════════

MARATHI FARMER:
  1. Opens app → Selects "मराठी"
  2. Registers farm in Shirdi
  3. Goes to Dashboard → AI Assistant
  4. Taps microphone
  5. Speaks: "मी कोणते पीक लावावे?"
     (What crop should I grow?)
  6. App recognizes speech (Speech-to-Text)
  7. Sends to Gemini API with context
  8. Receives response in Marathi:
     "आपल्या दोमट मातीत धान वाढवा..."
  9. Response auto-plays via speaker 🔊
  10. Farmer understands in their language!
